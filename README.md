# GYM by Alkis (iPhone)

Άνοιξε τη διεύθυνση της εφαρμογής στο **Safari** του iPhone → κουμπί **Κοινοποίηση** (τετράγωνο με βελάκι) → **Προσθήκη στην οθόνη Αφετηρίας** → **Προσθήκη**.

Για αλλαγές: αντικατέστησε το `index.html`. Το iPhone παίρνει τη νέα έκδοση την επόμενη φορά που θα ανοίξει την εφαρμογή με internet.
